XOOX WP Hacker Wordlists

This directory is reserved for non-sensitive security assessment wordlists.

XOOX WP Hacker does not provide or use credential brute-force lists, stolen credentials, leaked passwords, or authentication-bypass data.

Examples of permitted wordlists:

* Common WordPress paths
* Security testing payload identifiers
* Non-sensitive discovery terms
* Local lab testing data

Use only against WordPress installations you own or have explicit permission to assess.
